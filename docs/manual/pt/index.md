# Manual do Tramado

[English](../en/index.md) · **Português** · [Español](../es/index.md)

O Tramado guarda num só sítio tudo o que diz respeito a cada uma das suas disciplinas: as aulas que grava e as
respetivas transcrições, os documentos e os textos legais, os seus apontamentos, os exames anteriores e a conversa da
turma. Funciona no seu computador, não precisa de conta e partilha uma disciplina diretamente entre os computadores dos
colegas.

Este manual é da versão 0.1 (versão candidata 0.1.0-rc.2). Foi testada em Linux; as versões para Windows e macOS ainda
não foram testadas.

## Palavras usadas no Tramado

| Palavra | Significado |
|---|---|
| Disciplina | Uma cadeira que está a frequentar: uma pasta com as aulas, documentos, apontamentos e exames. |
| Aula | Uma sessão gravada de uma disciplina, com a gravação, a transcrição, os marcadores e os apontamentos. |
| Turma | Os colegas com quem partilha uma disciplina. |
| Organizador | Um membro que decide se quem chega precisa de autorização, pode remover pessoas e tornar outros organizadores. |
| Palavras de verificação | Duas palavras que identificam um computador, por exemplo *wavy-alpaca*. Compare-as para ter a certeza de quem entrou. |
| Transcritor | O computador que transcreve uma aula para toda a turma (só um por aula). |
| Citação | Um número numa resposta da IA que abre a página, o artigo ou o momento da aula de onde a resposta vem. |

## Teclado

<kbd>Ctrl</kbd>+<kbd>K</kbd> (<kbd>⌘</kbd>+<kbd>K</kbd> num Mac) pesquisa em tudo e executa comandos. <kbd>F1</kbd>
ou <kbd>?</kbd> mostra todos os atalhos de teclado do ecrã em que está.

As imagens deste manual vêm da biblioteca de exemplo (ecrã de boas-vindas › **Experimentar o exemplo**): as
disciplinas, as pessoas e os documentos são fictícios.
