# Contributing to Tramado

Thank you for helping. Tramado holds students' lectures, notes and class chats, and shares them between classmates'
computers, so correctness, privacy and plain language matter more than speed.

## Before you start

- For anything beyond a small fix, open an issue first so we can agree on the approach.
- **Use fictional material only** in issues, pull requests, tests, fixtures and screenshots: no real lecture
  recordings, transcripts, classmates' names or chat messages. The browser demo (`npm run dev:web`) has a fictional
  class library made for this, and `app/src/demo/` shows how it is built.
- **Never paste an OpenRouter key**, an account id (`user_id`), a generation id, credit or usage figures, or an e-mail
  address into the repository, an issue or a log. Saved model outputs go through `node tools/redact-fixtures.mjs`
  first, and `npm run check:leaks` must pass before every push. The repository is public.

## Development

[AGENTS.md](AGENTS.md) has the commands, the layout, the rules and the glossary; the
[architecture](docs/dev/architecture.md) is the contract between the parts, and the
[class folder format](docs/spec/class-folder-v1.md) and the [sync protocol](docs/spec/sync-protocol-v1.md) are the
specifications of what is written to disk and sent between computers. The checks every pull request must pass (CI runs
them too):

```bash
npm run check:leaks
npm run typecheck                          # also fails on a missing translation key
npm test
npm run --workspace app check:privacy      # PRIVACY.md matches app/src/core/privacy/flows.ts
npm run build
npm run lint:rust:lite && npm run test:rust
npm run test:contract                      # real Syncthing, Linux
```

Test interface changes in the browser demo, in light and dark themes, at the smallest window (1000 × 660) and at a
fractional scale (`npm run peek -- … --scale=1.25`), and check that everything works from the keyboard.
`node tools/peek-matrix.mjs --axe` screenshots every registered screen state and runs an accessibility check on each.

## Three languages

Tramado ships in English, European Portuguese and European Spanish: the interface, the manual, the privacy page and
the release notes.

- A change that adds or changes visible text updates `app/src/core/i18n/locales/{en,pt,es}/<namespace>.ts` in the
  same commit; the typecheck fails on a missing key.
- A change in how something is done updates the manual in `docs/manual/{en,pt,es}/`. New pictures come from
  `npm run screenshots` (see AGENTS.md, "Manual screenshots").
- Portuguese is from Portugal (ecrã, ficheiro, transferir, definições; Disciplina, Aula, Exame, Turma, apontamentos)
  and Spanish from Spain (ordenador, archivo, ajustes; Asignatura, Clase, Examen, apuntes), addressing the reader
  formally ("você" implied, "usted"). Keep to the glossary in AGENTS.md.
- If you do not write one of the languages, say so in the pull request and we will help. Please do not submit machine
  translation unreviewed.

## Privacy

Tramado has no server and makes no connection of its own beyond what [PRIVACY.md](PRIVACY.md) lists. Pull requests
that add analytics, telemetry, remote content or a new kind of connection will not be accepted without an issue that
agrees on it first. Anything new that sends data off the computer must be added to `app/src/core/privacy/flows.ts`,
with `PRIVACY.md` regenerated by `npm run gen:privacy`. The app's window must keep having no network access: all
connections go through the Rust side and its host allow-list.

## Commits

Explain in the commit message what changed and why. Sign off every commit
([Developer Certificate of Origin](https://developercertificate.org/)) to certify that you wrote it or have the right
to submit it under the project's licence:

```bash
git commit -s -m "Explain what changed and why"
```
